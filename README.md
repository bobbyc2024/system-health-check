# System Health Check

A simple Bash script for checking system health and basic system information on macOS.

## 🚀 Features

- Displays system uptime
- Checks disk usage
- Displays memory information
- More system health checks coming soon

## 🛠️ Built With

- Bash
- macOS command-line utilities

## ▶️ Usage

Run the script with:

```bash
bash health_check.sh
```
